# 研究假设与实验设计

## 1. 研究定位

本文档将贡献表述为可检验的系统设计，不将 DGGT、Splatt3R、3DGS 或 Hybrid A* 本身视为原创算法。核心假设是：前馈高斯场的几何不确定性可以被保留到占据建模，并改善泊车规划对窄通道与未知区域的处理。

## 2. 设计假设

### H1：前馈重建降低场景适配成本

DGGT 直接由视频预测位姿、深度和高斯场，避免每个场景进行长时间的 per-scene 优化。比较指标为重建延迟、显存占用和场景几何误差。

### H2：协方差风险图优于中心点近似

保留各向异性尺度与旋转协方差，理论上能更准确地描述高斯覆盖范围。比较指标为独立几何碰撞率、窄通道通过率、规划成功率和保守性。

### H3：未知区域约束减少过度通行

将 known 掩码与风险分数分离，可避免把观测缺失误认为空闲。比较指标为未知区域穿越率与任务拒绝率。

### H4：闭环评估揭示规划—执行差异

规划和仿真复用车辆轮廓碰撞检测，以终点误差、碰撞停止和换挡次数评估轨迹，而不是只报告开环路径长度。

## 3. 可复现消融

~~~powershell
python -m parking_gs.cli demo
python -m parking_gs.cli evaluate --scene outputs/demo/scene.npz --ablation --output outputs/demo_ablation.json
~~~

ablation 比较 covariance 与 centers 两种地图表达，其余规划和车辆参数保持不变。传统栅格 A* 通过 API 的 planner=astar 作为规划基线。reference_collision 仅表示内部一致性，不是独立真实碰撞标签。

## 4. 建议实验矩阵

| 因素 | 设置 | 主要指标 |
|---|---|---|
| 地图表达 | centers / covariance | 碰撞率、成功率、通道宽度 |
| 膨胀 | 0、0.06、0.12、0.24 m | 可达性与保守性 |
| 分辨率 | 0.15、0.25、0.40 m | 时间与边界误差 |
| 观测 | 全量、稀疏、遮挡 | 漏检与 unknown 拒绝率 |
| 监督 | RGB、RGB+深度 | PSNR、深度误差、几何误差 |
| 任务 | 垂直、平行、斜向 | 换挡、轨迹长度、终点误差 |

正式实验应使用多个场地和起点，并按场景划分数据。失败任务计入成功率；碰撞真值应来自测量几何、仿真 mesh、激光雷达或人工标注。

## 5. 边界

当前系统未实现可微规划反馈、学习型占据概率、动态高斯时序、车位检测、视觉定位、MPC、CARLA/ROS2 或实车通信。若研究目标是端到端控制，需要新增控制标签和联合训练目标。
