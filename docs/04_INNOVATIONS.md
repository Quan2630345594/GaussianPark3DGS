# 创新设计、实验方案与研究边界

## 1. 如何描述创新

本项目的创新定位是**面向泊车任务的前馈 3DGS 到占据图再到 Hybrid A* 的工程闭环**。下列设计已经有对应代码，但尚无真实视频实验来证明优于现有方法。不能把 DGGT、Splatt3R、3DGS 或 Hybrid A* 本身作为本项目首创，也不能据此直接宣称论文级新颖性。

### A. 视频前馈模型与安全地图解耦

输入只需要视频、模型代码和权重；重建适配层把 DGGT 的预测高斯统一为本项目的 `scene.npz`。地图、规划和前端不依赖某个模型内部类，后续可以替换 DGGT、Splatt3R 或自研网络。

- 代码：`feedforward.py`、`scripts/dggt_export_scene.py`。
- 可检验假设：相较每个新场景再优化数千步，前馈推理降低建图延迟。
- 限制：模型权重、坐标尺度和长视频窗口对齐仍需用户负责，当前没有直接证明实时性。

## 2. 已实现设计

### A. 将可视化高斯协方差用于泊车风险建图

传统简单接法常把重建结果降为点中心障碍。本项目保留高斯旋转和各向异性尺度，将 XY 协方差与可调几何膨胀结合，构造对窄通道敏感的风险图。高度支撑过滤分离地面与车辆碰撞层。

- 代码：`Scene.covariance()`、`build_grid()`。
- 可检验假设：相较忽略协方差的中心近似，能减少体积边缘碰撞，但可能缩小可达区域、降低成功率。
- 限制：渲染尺度不等同于物理边界；透明度不是占据概率；必须用独立真实几何评估才能证明效果。

### B. 已知区域约束与几何风险分开建模

不把“没有高斯”自动解释成“没有障碍”。通过单独的 known 掩码保留未知空间，将已核验区域与风险阈值共同用于规划和控制碰撞判定。

- 代码：`Grid.known`、`in_polygon()`、`collision()`。
- 可检验假设：在视角缺失时减少穿越未知区域的路径。
- 限制：当前 known 来自人工配置，而非在线传感器可见性推断；它是工程安全约束，不是新型概率占据融合算法。

### C. 重建、规划、执行在同一米制坐标中可追溯

场景 NPZ 保存单位、Z 轴、场地范围和任务信息；前端同时显示重建、BEV 风险、计划与实际仿真轨迹。终点误差来自闭环仿真结果，任务日志与 JSON 结果可导出。

- 代码：`scene.py`、`server.py`、`frontend/app.js`。
- 可检验假设：能更快定位尺度错误、路径贴障和控制跟踪偏差。
- 限制：这是可复现工程贡献，不直接代表规划算法性能领先。

### D. 与规划风险一致的闭环碰撞停止

规划和执行复用车辆轮廓/未知区域判定。即使计划无碰撞，执行偏差触及障碍时仍会停车并标记失败，避免用规划轨迹代替控制表现。

- 代码：`planner.collision()`、`control.simulate()`。
- 可检验假设：能揭示开环可行、闭环失败的任务。
- 限制：目前是理想运动学仿真，没有实车制动距离模型。

## 3. 已提供消融入口

```powershell
python -m parking_gs.cli demo
python -m parking_gs.cli evaluate --scene outputs/demo/scene.npz --ablation --output outputs/demo_ablation.json
```

当前 CLI 的 `--ablation` 比较 `covariance` 与 `centers` 两种地图：centers 用小的各向同性核替代原始 XY 协方差，其余参数保持一致。默认规划器是 Hybrid A*；需要栅格 A* 对照时通过 API `planner=astar` 显式切换。两种地图均记录展开数、路径长度和控制结果。这个 reference_collision 只是内部一致性指标，**不是独立真实碰撞标签**。结果中保留计划、执行轨迹、失败原因和耗时。

## 4. 建议的正式实验矩阵

| 因素 | 可选设置 | 需要观察 |
|---|---|---|
| 地图表达 | 点中心近似 / 完整协方差 | 成功率、独立几何碰撞率、通道通过率 |
| 几何膨胀 | 0 / 0.06 / 0.12 / 0.24 m | 保守性与可达性权衡 |
| 分辨率 | 0.15 / 0.25 / 0.40 m | 规划耗时、边界误差 |
| 输入视角 | 全量 / 稀疏 / 局部遮挡 | 漏检、未知区域拒绝率 |
| 重建监督 | RGB / RGB+深度 | PSNR、深度误差、障碍几何误差 |
| 任务类型 | 垂直 / 平行 / 斜向停车 | 换挡数、轨迹长度、终点误差 |

只有前两种地图表达已经被 CLI 自动化遍历。其余实验需要修改配置/调用函数或补充实验驱动，不应声称已有完整自动 benchmark。

至少使用多个场地和多个起点；按场景划分训练/验证/测试，固定任务、随机种子、车辆参数和计算预算。独立碰撞真值可来自测量过的仿真 mesh、激光雷达或人工标注几何。对失败任务也计入成功率，不能只展示成功视频。

## 5. 尚未实现的可选研究方向

可微规划损失反馈到高斯几何、学习型占据置信度、动态高斯时间建模、车位检测、视觉定位、MPC、CARLA/ROS2 接口、多相机鱼眼原生训练，都属于未来扩展，本交付不声称具备这些能力。如果论文要求“单网络端到端控制”，需另外采集控制标签并设计联合训练，而非只修改本项目标题。
